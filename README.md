# E-Commerce-Product-Performance-SKU-Rationalization-Engine

# Project Summary

This project, **E-Commerce Product Performance & SKU Rationalization Engine**, is an end-to-end business analytics solution developed over a 20-day sprint using **Excel, SQL, Python, and Power BI**.

The analysis used the **Order Delivery Performance Dataset**, covering **10,000 orders and 2,900 unique customers**. The project focused on understanding order value, shipping costs, delivery performance, regional performance, product categories, customer experience, and operational efficiency.

The project began with data profiling and cleaning, followed by Excel-based summaries, SQL KPI analysis, Python exploratory and statistical analysis, and finally an interactive Power BI dashboard.

The Power BI dashboard provides an **Executive Overview, Trends & Operations, Segment Performance, Product/SKU Rationalization, and Business Recommendations**. It includes KPI cards, slicers, trend analysis, and drill-down functionality from **Region → Warehouse → Courier**, allowing management to identify the operational causes behind delivery problems.

Key findings include a **₹251.41M total order value**, **17.16% delay rate**, **8.12% cancellation rate**, and approximately **25.28% of orders requiring delivery attention**. Central recorded the highest delay rate, while South performed comparatively better. Fashion was identified as a leading product category by order value and volume.

The project recommends improving delivery reliability, investigating regional and logistics inefficiencies, optimizing shipping costs, protecting high-performing categories, improving customer experience, and using data-driven **Grow, Optimize, Investigate, and Rationalize** decisions for future product and category management.

Overall, the project demonstrates how raw e-commerce data can be transformed into **validated KPIs, interactive dashboards, actionable insights, and business recommendations** to support better management decision-making.
